## 📖 About the Project

**Version 1.5.1** of G.D.P retains all features from the original version and introduces a set of visual improvements for the terminal: ASCII art banners, stylized bordered menus, and a more organized and professional data presentation.

For the full feature documentation, please refer to the [main version README](../README_EN.md).

---

## ✨ What's New in v1.5.1

- 🎨 **ASCII Art Banners** — Program title displayed with ASCII art in the terminal
- 📐 **Bordered Menus** — Menus reorganized with separators and enhanced formatting
- 🖥️ **Refreshed Layout** — Better visual organization of all terminal output
- ✅ **All v1.0 Features** — No feature was removed
